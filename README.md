Online Photography Print Selling Platform
 Project Overview
The Online Photography Print Selling Platform is a web-based application that allows photographers to showcase and sell their photographs as high-quality prints online

Customers can browse available photographs, add their favorite prints to a cart, and place orders easily. The platform also provides an admin side for managing photographs and customer orders

 Objectives

- To provide an easy platform for selling photography prints online.
- To help photographers showcase their work digitally.
- To allow customers to browse and purchase photographs easily.
- To manage products, users, and orders efficiently.

 Features

 User Features

- User Registration and Login
- Browse Photography Prints
- View Available Products
- Add Products to Cart
- Place Orders
- View Order Details

 Admin Features

- Admin Login
- Add New Photography Prints
- Delete Photography Prints
- View Customer Orders
- Update Order Status

 Technologies Used

- Python
- Streamlit – Web application framework
- SQLite – Database
- HTML/CSS – Interface styling
- Git & GitHub – Project version control

 How to Run the Project

1. Clone the Repository

git clone <your-github-repository-link>

2. Open the Project Folder

cd Online-Photography-Print-Store

3. Install Required Packages

pip install -r requirements.txt

4. Run the Application

streamlit run app.py

The application will open in your web browser.

 How the Platform Works

User → Register/Login → Browse Prints → Add to Cart → Place Order → View Order Status

Admin → Login → Manage Prints → View Orders → Update Order Status
